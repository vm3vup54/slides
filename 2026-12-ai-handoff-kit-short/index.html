    與本機下載位置。

    打開交接簿
    
  
    每種資訊，只有一個正本
    
  
    

    


    
  
    三句口令
    
  
    開工、換手、收工，是三件不同的事
    
  
    公司 Windows開工工作換手新對話收工
    經 GitHub 交接
    家裡 Mac開工接著做收工
    
  
    開工
    在這台開始做事
    只上傳簽到
    換手
    同一台電腦換新對話
    不上傳
    收工
    要離開這台電腦
    確認清單後一次上傳
    

    三句口令示範為第二級日常使用；新電腦須先完成首次下載與接入。
    

    


    
  
    界線
    
  
    它不能替你做什麼
    
  
    忘記收工
    它不會替你存檔
    寫了規則
    不保證每次都照做，重要的事要人確認
    GitHub
    不是完整備份，沒提交或太大的檔案不在上面
    兩種 AI
    同一台電腦不要同時改檔案
    資料能不能上雲
    依機關規定判斷，不是 AI 判斷
    最後一關
    上傳前，自己看過清單
